# Sons originais do Vereda

Sinais sintetizados especificamente para o aplicativo, sem samples de terceiros. PCM WAV mono, 22050 Hz, 16 bits.

- correct.wav: duas notas ascendentes (Mi5/Lá5), 0,42 s.
- retry.wav: duas notas suaves (Sol4/Fá4), 0,36 s.
- complete.wav: arpejo Dó5/Mi5/Sol5/Dó6, 0,95 s.

Picos normalizados para aproximadamente 80% da escala PCM. Reprodução com volume configurável (40%, 80% ou 100%; padrão 80%), sem repetição contínua. O controle do aparelho e a preferência local do app continuam disponíveis.
